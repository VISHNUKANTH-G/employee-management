# Employee Management System

This is a simple Employee Management System made using only HTML, CSS and JavaScript.

I made this project to practice basic front-end concepts and JavaScript like DOM manipulation and localStorage.

## What this project can do
- Add employee details
- Edit employee details
- Delete employee details
- Saves data in browser using localStorage

## Tech used
- HTML
- CSS
- JavaScript

## How to run this project
1. Download or clone this repository
2. Open `index.html` in any browser
3. That’s it 🙂

This is a project made for practice and showcase purpose ONLY.
